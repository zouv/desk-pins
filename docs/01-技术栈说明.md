# 技术栈说明

| 用途 | 选型 | 原因 |
|---|---|---|
| 界面 | WPF | 用户明确选择，原生独立窗口，可自定义标题栏和便签皮肤 |
| 语言与运行时 | C# / .NET Framework 4.8 / x64 | 延续 ExplorerTabs 的构建环境，Windows 10 / 11 易部署 |
| 文本编辑 | WPF RichTextBox / FlowDocument | 富文本与 RTF 读写，无浏览器运行时 |
| 系统交互 | Windows API | 托盘、全局热键、窗口附着和点击穿透 |
| 存储 | 系统 winsqlite3.dll / SQLite | 元数据与内容分离，事务保存、搜索和备份，无额外数据库包 |
| 扩展 | 本地命令接口与事件 | 外挂可独立开发，核心无需常驻脚本环境 |

目标界面为熟悉的纸质便签和原生菜单；不进行全新的交互设计。启动和占用指标必须通过指定场景测量，不能依据技术栈直接保证。

## 当前性能基准

2026-11-07，Windows 10 x64，.NET Framework 4.8，Release 构建；独立数据、无网络 / 邮件、各测 3 次。时间为程序入口到 Dispatcher 空闲；CLR 与文件缓存已预热，未确认首帧，不代表冷启动。

| 场景 | 时间中位数 | 私有内存中位数 | 工作集中位数 |
|---|---|---|---|
| 1 张文本便签 | 1721 ms | 44.65 MiB | 74.20 MiB |
| 10 张文本便签 | 2471 ms | 51.62 MiB | 84.86 MiB |

这是当前结果，启动速度仍有优化空间。命令为 `sh manager.sh benchmark`；原始结果存于忽略入库的 `.runtime/benchmark/`。

独立解压包的进程检查中，2 张文本便签空闲时私有内存 45.91 MiB、工作集 81.22 MiB，5 秒新增 CPU 时间为 0 ms。该短采样仅描述本次环境，不代表长时间或大量便签场景。
