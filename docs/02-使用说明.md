# 使用说明

## 运行

开发版面向 Windows 10 / 11 x64，需要 .NET Framework 4.8。双击 `dev.bat` 构建并运行，`run.bat` 启动已有构建，`package.bat` 生成免安装包。命令与前置条件见根 README。

默认数据目录为 `%LOCALAPPDATA%/DeskPins`；也可在设置-数据中选择自定义目录（重启后生效），或用 `DeskPins.exe --data-dir "C:\path\to\notes"` 临时覆盖。同一目录只允许一个实例，不同目录互相独立。

## 桌面便签

- 双击托盘新建，单击前置；右键提供新建、显隐、管理、设置与退出；导入、备份和恢复已移到设置-数据。
- 拖动标题栏移动，边缘缩放，双击卷起（可在设置-桌面改为不执行或打开管理便签）。右键标题栏调整样式、透明、锁定、穿透、秘密模式、提醒与收藏。
- 文本内容右键提供字体、列表、对齐、链接、高亮和查找。向空文本便签粘贴图片会转为图片便签；图片右键切换绘图工具、选区、裁剪与变换。
- 修改约 600 ms 后自动保存，关闭进入“已关闭”，可从管理器恢复。永久删除有确认；退出保存待提交编辑。

| 快捷键 | 操作 |
|---|---|
| Ctrl+N / Ctrl+D | 新建 / 关闭 |
| Ctrl+T / Alt+R | 置顶 / 卷起 |
| Ctrl+Shift+L | 锁定内容 |
| Ctrl+M / Ctrl+O | 管理 / 设置 |
| Ctrl+Shift+A / Ctrl+L / Ctrl+Shift+O | 闹钟 / 休眠 / 重复 |
| Ctrl+G | 休眠到明天的配置时间 |
| Ctrl+S / Ctrl+Shift+S | 导出 / 保存全部 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| Alt+0–9 | 应用样式；选中文本时只改选区 |
| Alt+F / Alt+V | 复制 / 应用文字格式 |

全局热键默认关闭，可在设置指定；便签快捷键也可自定义。设置窗口是任务栏可见的独立窗口，打开时仍可编辑便签；使用左侧分类导航，共应用、桌面、外观、内容、提醒、网络、邮件、快捷键和数据 9 类。应用页可切换中文 / English，保存后界面、管理器与托盘立即更新；快捷键页分全局与应用内两组，每行可启停并点击按键框录入组合键或普通按键，全局组还提供“管理便签”。便签和堆叠窗口均可拖拽边框调整尺寸；便签自动吸附在松手后生效，吸附距离 / 间隙可在设置中调整。

## 管理、提醒与附着

管理器左侧是分类图标栏。Stored / Stacks / Tags 使用“大纲 → 便签列表 → 内容”三栏布局，可拖拽两条分隔条并分别记住宽度；Desktop、Attached、Sleeping、Recurring、Closed 等使用便签列表 + 内容两栏。Home 显示桌面、堆叠、附着、休眠、重复、关闭、收藏的数量条和数据库 / 文本 / 图片统计。支持多选、拖放和搜索结果。穿透便签可从管理器关闭 Ghost。

提醒支持绝对时间、相对分钟、每天、每周指定日、每月指定日 / 星期位置、每年和固定间隔。错过多个循环只生成一次，是否阻止重复可配置。唤醒声音与闹钟分开配置；闹钟左键停止，右键稍后提醒。

附着可选择外部窗口，标题和类名支持 `*` / `?`，可使用相对位置；目标隐藏、最小化或关闭时便签隐藏。实际外部窗口和多屏行为仍待验收。

## 保存、备份与迁移

收藏文件夹可切换加密；先设置密码并解锁，锁定后内容卸载。密码没有找回功能；新加密设置不改变既有备份。

托盘不再承载导入与备份操作；请打开设置-数据执行导入便签、从传输文件导入、导入 Stickies v10、备份、完整 / 合并 / 选择性恢复以及救回屏幕外便签。完整替换前先备份当前库。单张导出支持 `.dpn`、文本、RTF、PNG；`.dpx` 用于在 DeskPins 实例间传输，在数据库接收成功后消费。

在设置-数据可更改数据目录：目标目录为空时会先复制当前数据库；目标已有 DeskPins 数据库时直接切换到该目录；保存后需要重启 DeskPins。使用 `--data-dir` 启动时命令行目录优先于设置。

Stickies v10 导入支持已实现字段的非加密便签；原版加密便签明确跳过。原版 `.sti`、transfer.ini、`.ssk`、语言 DLL 与全部设置兼容尚未完成。当前 `.sti` 导出是 `#sticky` 传输文本，不保证被原版导入；迁移时保留源文件。

## 联系人与扩展

TCP 与 SMTP 默认关闭，配置后手动启用。邮件设置可选择默认客户端打开正文草稿，图片和 RTF 附件使用 SMTP。联系人支持地址、邮件、组路径和收藏序号，JSON 来源支持本地文件或 HTTP URL。外部邮件、原版网络互通和联系人服务器尚未验收。

皮肤示例为 `assets/skins/classic-plus.json`，支持标题栏颜色、边框和按钮动作。C# 编辑器、存储、调度与系统集成入口见 ARCHITECTURE。

通过当前用户的 Named Pipe 调用正在运行的实例：

```text
DeskPins.exe --api "do new sticky Hello" --output "C:\path\to\result.txt"
DeskPins.exe --api "get desktop list" --output "C:\path\to\result.txt"
DeskPins.exe --api "do stickymenuadd custom 自定义动作" --output "C:\path\to\result.txt"
DeskPins.exe --api "get events" --output "C:\path\to\events.txt"
```

支持部分 Stickies 风格指令和菜单事件；完整原版 API 兼容尚待补齐。`--data-dir` 必须与目标实例一致。

## 文档维护

运行 `sh manager.sh verify` 执行构建、回归与文档检查。协作入口为 AGENTS，结构导航为 ARCHITECTURE，完成度为 ROADMAP，断点为 HANDOFF。未测场景不可标记“已验证”。
