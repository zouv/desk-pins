# Stickies 功能对照

基准：Zhorn Stickies 10.2a 官方帮助和公开 API。参考软件仅在忽略入库的 `.runtime/reference`，产品独立实现，使用自制资源。

状态仅描述有证据的范围。对象回归不代表实际界面、外部协议或原版格式等价；整体仍为开发版，尚未完成完整复刻验收。

|---|---|---|---|
| F01 | 托盘、新建、显隐、前置、退出、单实例 | 已实现；IPC、显隐幂等、包启动与第二实例导入通过 | 托盘实测 |
| F02 | 文本 / RTF、格式、列表、对齐、链接、撤销、查找、打印 | 已实现；RTF、嵌入图片重载、跨格式查找回归通过 | 富文本其他细节、打印与原版对照 |
| F03 | 图片、画笔、形状、文字、裁剪、旋转、导出 | 已实现；像素、尺寸、撤销回归 | 实际绘图、屏幕截取、全部工具验收 |
| F04 | 拖缩、吸附、多屏、置顶、卷起、透明、穿透、锁定、秘密模式 | 已实现；卷起 / 锁定回归 | 多屏 DPI、Ghost、分组拖动和显隐实测 |
